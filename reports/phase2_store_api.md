## 한 줄 요약

잠정실적 공시 34,687건을 **실적 하나(회사 · 연결/별도 · 기간)당 한 묶음**으로 잇고, 97.5% 에 **분 단위 최초 공개 시각**을 붙였으며, 시장 예상치가 있는 236건에 **깜짝 판정**을 달았다. 이 표를 읽는 API 를 만들었고, 정한 불변조건 7가지는 위반 0건이다.

## 1. 버전 묶음

| | 수 |

- **이전 버전은 덮어쓰지 않는다.** 묶음마다 '현재 값' 은 하나다.
- **한계 — 정정공시 원문이 없다.** 정정공시 2,118건은 목록에만 있고 원문이 모이지 않았다. 그래서 그 묶음(1,928개)은 API 가 "정정 전 숫자" 를 보여 주며 `CORRECTION_NOT_REFLECTED` 와 경고를 함께 낸다. 정정 전 숫자를 현재 값인 척하지 않는다.

## 2. 최초 공개 시각

DART 접수번호와 KIND 접수번호는 체계가 달라, 종목코드 · 날짜 · 정정 여부 · 연결/별도 · 자회사 여부가 같은 공시끼리 그날 안의 순서로 맞췄다.

| 맞춤 결과 | 건수 |
|---|---:|
| 분 단위 시각을 붙임 | 33,805 (97.5%) |
| 같은 묶음에 공시 수가 달라 붙이지 않음 | 35 |
| KIND 에 짝이 없음 | 847 |

장 시간 구분: 장중 18,377 · 장 마감 뒤 13,436 · 장 전 2,012 · 휴장일 15.
**최초 공개 시각은 묶음의 첫 버전 시각**이고 정정으로 바뀌지 않는다.

## 3. 깜짝 판정 (영업이익)

- 시장 예상치는 **기사에서 뽑은 증권사 컨센서스**(에프앤가이드 등 인용) 705개 사건 · 313개 회사다. 유료 컨센서스 데이터가 아니라 범위가 작고 기사 추출 오류가 있다.
- 판정은 **묶음의 첫 공시**에만 한다. 기준 시각은 최초 공개 시각이고, 그보다 먼저 나온 기사 중 가장 최근 것을 쓴다.
  - 이렇게 정한 이유: 삼성전자 2024년 2분기는 7월 5일 요약, 7월 31일 상세를 냈다. 두 번째 공시 기준으로 고르면 7월 7일 기사의 "10조4000억원을 **발표하자**" 를 예상치로 잡아, 이미 나온 숫자와 비교하게 된다.
- 차이 ±5% 안 부합, 5~10% 상회 · 하회, 10% 넘으면 어닝 서프라이즈 · 쇼크.
- **판정 보류 30건**: 예상치 기사가 45일보다 오래됨 28 · 기사 문장은 손실을 말하는데 숫자가 양수(부호 의심) 2. 숫자는 보여 주고 판정만 비운다.

| 판정 | 건수 |
|---|---:|
| 어닝 서프라이즈 | 92 |
| 어닝 쇼크 | 74 |
| 부합 | 41 |
| 상회 | 20 |
| 하회 | 9 |

판정이 깜짝 쪽으로 쏠린 것은 기사가 실적이 크게 엇갈리는 회사를 더 자주 다루기 때문으로 보인다(표본 편향). 판정 수는 2023년 이후에 몰려 있다.

## 5. API

| 요청 | 하는 일 |
|---|---|
| `GET /v1/filings?date=&limit=&offset=` | 최근 잠정실적 목록(공개 시각 순). 매출 · 영업이익 · 순이익과 전년 대비, 깜짝 판정 |
| `GET /v1/filings/{rcept_no}` | 공시 한 건: 항목별 숫자(원 단위) · 공시에 적힌 증감률과 다시 계산한 증감률 · 검증 결과 · 원문 오기 후보 · 근거 · 버전 목록 · DART 원문 링크 |
| `GET /v1/companies/{stock_code}/earnings` | 한 회사의 기간별 현재 값(최근 순, 연결 우선) |
| `GET /v1/companies/{stock_code}/earnings/{period}` | 기간 하나: `OK` · `CORRECTION_NOT_REFLECTED`(경고 포함) · `NOT_YET`(아직 공시 전, 오류 아님) |

대표 시나리오는 테스트로 고정했다(`tests/test_api.py`): 정상 조회 · 아직 공시 안 한 기간 · 원문을 못 읽은 정정공시 · 잘못된 입력(422 · 404).

## 6. 남은 한계

- 정정공시 원문 2,118건(위 1절). OpenDART 에서 받으면 `CORRECTION_NOT_REFLECTED` 가 대부분 사라진다.
- 기간 표시가 없는 공시 약 28% 는 접수일로 기간을 추정했고, 회사별 기간 목록에서는 빠진다(공시 한 건 조회로는 볼 수 있음).
- 깜짝 판정은 기사 기반 예상치가 있는 회사 · 분기만 된다.
